LIVE Giveaway Wheel — mobile PWA

Upload all files, including the api folder, to a new Vercel project. This version needs Vercel's serverless function for ScrapeCreators search. Open the deployed HTTPS URL on iPhone in Safari → Share → Add to Home Screen. Android: Chrome → Install app.

Open the menu (☰) to save your ScrapeCreators API key on this device, or set SCRAPECREATORS_API_KEY in the Vercel project's environment settings. Enter a TikTok username, tap Search, then select the real account result to add its nickname and avatar to the participant list. Search requires a live connection and an active ScrapeCreators key. There are no invented search results.

Tap SPIN to randomly select a listed participant and one of ten wheel prizes. Winner records are saved on this device. This app does not monitor live viewers or verify follows, comments, gifts or eligibility. It does not send or fulfill prizes. The images and names of prizes are a visual mockup; only offer prizes you will deliver.
